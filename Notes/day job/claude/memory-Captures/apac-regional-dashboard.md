**How it gets built.**
- The claude.ai HubSpot connector is read-only here; every write status is REQUIRES_REAUTHORIZATION.
- HubSpot has no API that creates reports. Its 2027-03 beta API only assembles dashboards from existing reports.
- So builds are click paths in the UI, written into the scope page, and each saved report is checked with manage_saved_reports FETCH. For the builder's labels and the Save-dialog fields, see [[report-guide-save-fields]].
- Connector SQL quirks:
  - `hs_object_source` is blocked; use `hs_object_source_label`.
  - GROUP BY and WHERE on CONTACT.prospective_chapter work.
  - LIMIT applies per bucket.
