Proof it reaches plugin copies too: `git-guardrails-claude-code`, `migrate-to-shoehorn`, `scaffold-exercises` and `setup-pre-commit` are model-invocable in the plugin (no `disable-model-invocation`) yet none appeared as `mattpocock-skills:*`, and all four sit in `skillOverrides` as `off` under a bare key. So a namespaced key is a no-op; the lever for one source is enabling/disabling the plugin, never an override.
