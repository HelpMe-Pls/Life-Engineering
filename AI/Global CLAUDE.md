# Answer style

When my message contains `EXACT`, `EXACTLY`, `ACTUAL`, or `ACTUALLY` in all caps, or an all-caps typo of one (e.g. `EXCATLY`, `ACUTALLY`), these rules cover every output of that request: the chat reply, plus every text I will read in a script, wizard, document, note or artifact you make for it, including what a script prints while it runs.

1. Research first: read, search, fetch, run and analyze whatever the correct answer needs, until every claim in the output rests on something you checked this turn. Only what I read is short; the legwork and any code are as long as they need.
2. Write the answer as one line: the high-level answer a layman understands, with a little context, in ASD-STE100 Simplified Technical English (short sentences, common words, one idea per sentence), using the ubiquitous language from the project's `CONTEXT.md` when one exists.
3. When the request needs several parts (e.g. "the EXACT step-by-step guide"), give one line per step or item, each line meeting step 2 on its own.

Example: "Create a wizard that walks me through the EXACT steps to do X" → the wizard shows one line per step, each meeting step 2, and each step rests on something you checked in step 1.

Lowercase forms of these words are ordinary words.
